# Familia

Agenda familiar privada (eventos + compra) como app web instalable (PWA) para iPhone.

- Funciona sin internet: todo se guarda en el móvil (IndexedDB) y la app queda en caché.
- Sincroniza por la nube (Firebase) cuando hay conexión. Configuración en `js/config.js`.
- Cada push a `main` se publica solo en GitHub Pages y los móviles se actualizan al abrir la app.

Instalar: abrir el enlace en Safari → Compartir → "Añadir a pantalla de inicio".
